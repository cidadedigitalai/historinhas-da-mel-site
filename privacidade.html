Política de Privacidade — Historinhas da Mel

Atualizada em 30/09/2026.

O aplicativo "Historinhas da Mel" é uma ferramenta interna usada apenas pelo dono do canal para publicar, no seu próprio canal do YouTube, vídeos animados criados por ele.

Dados acessados: apenas a permissão de enviar vídeos (YouTube Data API, escopo youtube.upload) e ler as informações básicas do próprio canal. Nenhum dado de outros usuários ou espectadores é coletado, armazenado ou compartilhado.

Armazenamento: o token de acesso fica guardado de forma segura (segredo criptografado) e é usado somente para publicar os vídeos do canal.

Crianças: os vídeos são marcados como "feitos para crianças" no YouTube. O aplicativo não coleta nenhum dado de crianças.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
